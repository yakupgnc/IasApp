# İaşApp Project Rules

## Git & GitHub Sync Workflow

- Whenever any requested code, style, configuration, or documentation change in this project is completed and verified, automatically stage, commit, and push the changes to GitHub (`origin main`) before finalizing the response.
- Use clear Conventional Commits messages (e.g., `feat: ...`, `fix: ...`, `style: ...`, `docs: ...`).
- Only skip committing/pushing if the user explicitly asks to keep changes local or if the work is incomplete/broken.
